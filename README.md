## 🚀 Come Eseguire

### ☕ Java
```bash
javac NomeFile.java
java NomeClasse
```

### ⚙️ C++
```bash
g++ -o programma file.cpp
./programma
```

### 🐍 Python
```bash
python file.py
```

### 🖥️ JavaFX
Apri il progetto in **IntelliJ IDEA** e premi ▶️ Run.  
> Assicurati di avere **JavaFX SDK** configurato nelle dipendenze.
