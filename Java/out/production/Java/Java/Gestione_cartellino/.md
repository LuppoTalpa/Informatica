
## Esercitazione Java: Sistema Gestione Presenze (HashMap & Java Time)

### Contesto

L'azienda **TechSolutions S.r.l.** ha bisogno di un software per monitorare gli ingressi dei propri dipendenti in ufficio. Il sistema deve tenere traccia di chi è presente e calcolare il tempo trascorso al lavoro.

### Obiettivi dell'esercizio

Sviluppare una classe Java che utilizzi una `HashMap` per memorizzare i dati e le API di `java.time` per la gestione cronologica.

#### Requisiti tecnici:

- **Struttura Dati**: Utilizzare una `HashMap<String, LocalDateTime>` dove la chiave è il nome del dipendente e il valore è l'orario di ingresso.
- **Librerie consigliate**: `java.time.LocalDateTime`, `java.time.Duration` e `java.util.HashMap`.

### Funzionalità richieste

Lo studente deve implementare i seguenti metodi:

1. **`registraIngresso(String nome)`**:
   - Aggiunge il dipendente alla mappa con l'orario attuale.
   - *Bonus*: Se il dipendente è già presente, il sistema non deve sovrascrivere l'orario ma avvisare che l'utente è già in ufficio.

2. **`registraUscita(String nome)`**:
   - Calcola quanto tempo il dipendente ha trascorso in ufficio (differenza tra orario attuale e orario di ingresso).
   - Stampa un messaggio con il riepilogo (es: "Marco è uscito. Tempo totale: 4 ore e 20 minuti").
   - Rimuove il dipendente dalla mappa.

3. **`stampaPresenti()`**:
   - Cicla sulla mappa e stampa l'elenco di tutti i dipendenti attualmente in ufficio e il loro orario di entrata formattato in modo leggibile (es: `dd/MM/yyyy HH:mm`).

4. **`filtraPerOrario(LocalDateTime soglia)`**:
   - Stampa i nomi di tutti i dipendenti che sono entrati **prima** dell'orario indicato dalla soglia.

---

### Esempio di Test (Main)

All'interno del metodo `main`, simulare il seguente scenario:

1. Registrare l'ingresso di 3 dipendenti (es: Anna, Luca, Giovanni).
2. Attendere qualche secondo o simulare ingressi avvenuti in passato.
3. Stampare l'elenco dei presenti.
4. Registrare l'uscita di uno dei dipendenti e verificare il calcolo della durata.
5. Provare a registrare un ingresso duplicato.
