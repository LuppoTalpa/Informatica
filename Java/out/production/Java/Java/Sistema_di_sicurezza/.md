### Esercizio: Il Framework "SmartCity Security"

**Obiettivo:** Gestire diversi dispositivi di sicurezza che possono rilevare pericoli, attivare allarmi o inviare dati
alla centrale, rispettando standard condivisi.

#### 1. Definizione delle Interfacce con Costanti e Default

- **Interfaccia `RilevatorePericolo`**:
    - **Costante Statica**: `double SOGLIA_CRITICA = 75.0;` (un valore standard sopra il quale scatta l'allerta).
    - **Metodo Astratto**: `double leggiLivello();`
    - **Metodo Default**: `default boolean isPericolo() { return leggiLivello() > SOGLIA_CRITICA; }`

- **Interfaccia `DispositivoAllarme`**:
    - **Metodo Astratto**: `void attiva();`
    - **Metodo Astratto**: `void disattiva();`
    - **Metodo Default**:
      `default void testSistema() { System.out.println("Esecuzione test sonoro/visivo in corso..."); }`

- **Interfaccia `TrasmettitoreDati`**:
    - **Costante Statica**: `String PROTOCOLLO = "MQTT";`
    - **Metodo Astratto**: `void inviaDati(String messaggio);`

---

#### 2. Implementazione delle Classi Concrete

Dovrai creare tre classi che combinano queste capacità in modo diverso:

1. **Classe `SensoreGas`**: Implementa `RilevatorePericolo` e `TrasmettitoreDati`.
    - Deve leggere un valore di gas.
    - Se `isPericolo()` è vero, deve usare `inviaDati` per segnalare l'emergenza usando la costante `PROTOCOLLO`.

2. **Classe `SirenaIntelligente`**: Implementa `DispositivoAllarme` e `TrasmettitoreDati`.
    - Oltre ad attivarsi/disattivarsi, deve inviare un messaggio alla centrale quando viene manomessa.

3. **Classe `DroneEmergenza`**: Implementa **tutte e tre** le interfacce.
    - È il dispositivo più complesso: rileva pericoli dall'alto, può attivare una sirena di bordo e trasmette
      video/dati.

---

#### 3. Logica di Gestione (Main)

Nel metodo `main`, simula questa situazione:

1. **Utilizzo delle Costanti**: Stampa la `SOGLIA_CRITICA` e il `PROTOCOLLO` direttamente richiamandoli dalle
   interfacce (es. `RilevatorePericolo.SOGLIA_CRITICA`).

2. **Test dei Default**: Crea un'istanza di `SirenaIntelligente` e chiama il metodo `testSistema()`. Nota come non hai
   dovuto scrivere il codice del test nella classe Sirena!

3. **Il "Protocollo Emergenza"**: Crea un metodo statico nel main chiamato `gestisciEmergenza(RilevatorePericolo r)`.
    - Se `r.isPericolo()` restituisce true, stampa: "Allarme rilevato!".
    - Fai un controllo: se `r` è anche un'istanza di `DispositivoAllarme` (usa `instanceof`), forza il cast e chiama
      `attiva()`.
