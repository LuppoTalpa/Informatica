#### **ACCESS GRANTED // CENTRAL SECURITY NETWORK: NIGHT CITY**

**Oggetto:** *Upgrade Sistema di Difesa "Aegis v2.0"*

"Ehi, Netrunner! Il vecchio sistema di gestione della sicurezza basato su array statici è stato bucato da un virus di
livello script-kiddie. Dobbiamo ricostruire il database delle unità di difesa usando una struttura dati più efficiente:
una **HashMap**. Abbiamo bisogno di velocità di ricerca istantanea tramite numero di serie, o la città cadrà nel caos
prima del prossimo reboot."

**OBIETTIVO:** Creare un sistema di gestione per le unità di sicurezza utilizzando classi astratte, ereditarietà e una
`HashMap` per l'archiviazione.

**FASE 1: IL PROTOCOLLO BASE (Astrazione)** Definisci la classe astratta **`SecurityUnit`**:

- **Attributi:** `codiceSeriale` (String), `modello` (String), `livelloAllerta` (int).
- **Costruttore:** per inizializzare tutti i campi.
- **Metodo Astratto:** **`attivaProtocollo()`** (non restituisce nulla).
- **Metodo Concreto:** `toString()` (Override per restituire i dettagli dell'unità).

**FASE 2: LE UNITÀ OPERATIVE (Ereditarietà)** Crea due classi concrete che estendono `SecurityUnit`:

1. **`PatrolDrone`**:

- Attributo extra: `autonomiaVolo` (int).
- Override di `attivaProtocollo()`: Stampa *"Drone [modello] in volo. Scansione biometrica in corso. Autonomia
  residua: [autonomiaVolo] min."*

2. **`DefenseTurret`**:

- Attributo extra: `settoreDifesa` (String).
- Override di `attivaProtocollo()`: Stampa *"Torretta [modello] agganciata al settore [settoreDifesa]. Armamenti pronti
  al fuoco!"*

**FASE 3: IL MAINFRAME (HashMap & Polimorfismo)** Crea una classe **`NightCityControl`** con il `main`. All'interno:

1. Dichiara una **`HashMap`** dove la **chiave** è il `codiceSeriale` (String) e il **valore** è un oggetto di tipo
   `SecurityUnit`.
2. Inserisci nel database almeno 3 unità (miste tra droni e torrette) usando il metodo `.put()`.
3. **Ricerca Rapida:** Simula una chiamata di emergenza recuperando un'unità specifica tramite il suo `codiceSeriale` (
   metodo `.get()`) e stampa i suoi dettagli.
4. **Protocollo Omega:** Utilizza un ciclo per scorrere **tutti i valori** della mappa (usando `.values()`) e richiama
   su ciascuno il metodo polimorfico `attivaProtocollo()`.

**REQUISITI TECNICI:**

- Incapsulamento: usa i modificatori di accesso corretti.
- Gestione Errori (Bonus): Se cerchi un codice seriale non presente nella mappa, fai stampare al sistema: *"ERROR: Unit
  ID not found. Breach detected!"*
