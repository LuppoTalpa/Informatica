## Esercizio: Il Contenitore Intelligente (`SmartBox`)

### Obiettivo

Realizzare una classe generica che funga da "deposito" per un singolo oggetto, ma con alcuni vincoli e funzionalità specifiche.

### Traccia

1. **Crea una classe generica `SmartBox<T>`**:

   - La classe deve poter ospitare un attributo privato di tipo `T`.
   - Implementa un costruttore che accetti un elemento di tipo `T`.

2. **Aggiungi i metodi standard**:

   - Un metodo `getItem()` per recuperare l'oggetto.
   - Un metodo `setItem(T item)` per sostituirlo.

3. **Implementa la logica di confronto**:

   - Aggiungi un metodo chiamato `compareType(Object o)`. Il metodo deve restituire `true` se l'oggetto passato come parametro è dello stesso tipo del contenuto della `SmartBox`, altrimenti `false`.

4. **Crea un Metodo Statico Generico**:

   - Scrivi un metodo statico chiamato `printDetails` che accetti una `SmartBox` di **qualsiasi tipo** (usa i *wildcards*) e ne stampi il contenuto e il nome della classe del contenuto.

---

### Esempio di esecuzione atteso

Se nel `main` scrivessi:

```java
SmartBox<Integer> box = new SmartBox<>(42);
System.out.println(box.compareType("Ciao")); // Dovrebbe stampare false
System.out.println(box.compareType(100));    // Dovrebbe stampare true
SmartBox.printDetails(box);                  // Stampa: Contenuto: 42 (Tipo: java.lang.Integer)
```

---

### Suggerimenti Tecnici

- Per il metodo `compareType`, ricorda che puoi usare `item.getClass().equals(o.getClass())` facendo attenzione ai valori nulli.
- Per il metodo statico con i wildcards, la sintassi corretta è `SmartBox<?>`.
